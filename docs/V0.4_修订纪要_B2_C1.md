## 一、代码侧落实情况（已实现并通过门禁）

### 1. B2：S2 单/多判定以「XML 器物号」为一级证据（rule_b 前置消解）
文件：`src/archaeopairs/parsers/keywords.py`（`refine_image_type`）

**问题**：原实现仅当 VLM 返回 legacy `line/line_drawing` 时按 XML 器物号个数细化；当 VLM 直接返回 `multi_line`/`single_line` 时不回降，rule_b（单器物多视图，图内有 ≥2 视图序号）会因"序号个数≥2"被误判为多器物 → 多器物线路 → 链①缺失 → seq_missing/E005 误报。

**修订**：线图家族统一以「XML 唯一器物号个数」判定：
- **唯一器物号 → `single_line`**（rule_b/整图归属；即便视觉见多个视图序号）——**无视 VLM 判 multi_line 也回降**；
- **多器物号 → `multi_line`**（无视 VLM 判 single_line 也升级）；
- **无 XML 信号 → 沿用视觉判定 image_type**（此时"图内序号个数"对 rule_b 多视图与多器物有歧义，**不得据此升降级**）。

**实证效应**：rule_b 形态（图题/图注恰 1 器物号）不再因视图序号多而误入多器物线路；无 XML 信号图的判定交由 VLM 视觉（对应 B1，本章节二已说明延后原因）。

## 六、迭代之二（V0.4.1）：S2 五分类重构——XML 器物号主判 + 关键词定线/彩（已确认实施）

> 决策（用户确认）：①零 XML 信号 → 直接 discarded；②plate_scene 并入 discarded、line_drawing 哨兵移除，枚举精简为 5 类；③线/彩家族仅靠关键词 `图版/圖版`（S2 不再调 VLM）；④五分类命名统一为 `*_artifact`。

### 新判定（`parsers/keywords.py::decide_image_class`）
```
N = 图注∪图题去重唯一器物号个数（图注有号优先，无号图题兜底）
  N==0 -> discarded                                     （不猜测，归档）
  N==1 -> single_plate_artifact | single_line_artifact （关键词图版/圖版）
  N>=2 -> multi_plate_artifact  | multi_line_artifact  （关键词图版/圖版）
```

### 新增/命名变更
| 旧 7 枚举 | 新 5 枚举 |
|---|---|
| single_line | **single_line_artifact** |
| plate_artifact | **single_plate_artifact** |
| multi_line | **multi_line_artifact** |
| multi_plate | **multi_plate_artifact** |
| plate_scene | → 并入 `discarded` |
| line_drawing | → 移除（不再产生） |
| discarded | discarded |

### 枚举精简与下游一致性
- `state.py`：`ImageType` 7→5；`CaseType` 同步 `single_line/single_plate` → `*_artifact`（`rule_a/rule_b/split_same_seq/range_split/seq_missing` 不变）。
- 路径核对：单器件类（line/plate）同走 `parse_single`（S7→S8 整图归属，仅 role/merge_mode 标签不同）——**路径一致**；`multi_line_artifact` 走 S3/S4→S5→S6→S8；`multi_plate_artifact`/`discarded` 归档（`END`）。

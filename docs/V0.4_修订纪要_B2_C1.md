### 1. B2：S2 单/多判定以「XML 器物号」为一级证据（rule_b 前置消解）
文件：`src/archaeopairs/parsers/keywords.py`（`refine_image_type`）

**问题**：原实现仅当 VLM 返回 legacy `line/line_drawing` 时按 XML 器物号个数细化；当 VLM 直接返回 `multi_line`/`single_line` 时不回降，rule_b（单器物多视图，图内有 ≥2 视图序号）会因"序号个数≥2"被误判为多器物 → 多器物线路 → 链①缺失 → seq_missing/E005 误报。

**修订**：线图家族统一以「XML 唯一器物号个数」判定：
- **唯一器物号 → `single_line`**（rule_b/整图归属；即便视觉见多个视图序号）——**无视 VLM 判 multi_line 也回降**；
- **多器物号 → `multi_line`**（无视 VLM 判 single_line 也升级）；
- **无 XML 信号 → 沿用视觉判定 image_type**（此时"图内序号个数"对 rule_b 多视图与多器物有歧义，**不得据此升降级**）。

**实证效应**：rule_b 形态（图题/图注恰 1 器物号）不再因视图序号多而误入多器物线路；无 XML 信号图的判定交由 VLM 视觉（对应 B1，本章节二已说明延后原因）。

## 七、迭代之三（V0.4.1）：S2 线/彩家族改为真实图像像素判定（PIL，非 VLM）

> 决策：将 S2 的「线图 vs 照片（彩版）」判定从关键词上移到图像像素分析（降采样色度统计），与工件主体分工——器物号仍以 XML 为准，线/彩族由图像本体判。新增依赖 `Pillow>=12.0`。

### 新模块 `parsers/image_classify.py`（像素家族算法，numpy 向量化）
```
1) 降采样：最长边缩到 96px（thumbnail）——色度/中间调为全局统计量，几乎无影响、大幅提速。
2) 逐像素通道极差 d = max(R,G,B)-min(R,G,B)；汇总 mean_chroma、pct20(d>20占比)；
   亮度 L=(R+G+B)/3，中间调 mid_ratio = L∈(64,192) 像素占比(%)。
3) 家族判定（阈值参考 21 书 16,160 图校准）：
   彩色   : pct20>=5 或 (mean_chroma>=8 且 pct20>=1)
   其余   : mid_ratio>=15 -> 灰度照片(gray)；否则 -> 线图(line)
   置信度 : color(pct<10) / gray(mid<28) / line(mid>8) 标 low 建议复核
```
> 算法说明：线图=双峰(大面积纸白+稀疏墨线)，中间调极少；灰度照片=连续影调，中间调高；
> 彩色=三通道显著分离(色度 d 高)。numpy 向量化或纯 Python 兜底。可选置信度 high/low。

### 拓图回退（方案A修正：关键词与像素**组合**，非单独强断）
> 因 96px 降采样后**拓片/拓本**（拓印线图）中间调落在 15~30，被 `MID_TH=15` 误判灰度照片(gray)→彩版族。
> 纯像素难以区分拓片与灰度照片，引入**显式拓图/线描语义词**（`拓片|拓本|拓印|线描|摹写`，
> `has_lineart_hint`），但**仅与像素组合消解**、绝不单独强断：
> * 像素判 `gray`(黑白照片) 且图题/图注含拓图词 -> **升级为线图族**（救回铜钱拓片）；
> * 像素判 `line` -> 线图族；像素判 `color` -> 彩版族（**关键词不覆盖强彩色**，避免误伤彩色图版）；
> * 无图/不可读 -> 关键词兜底（此时关键词单独生效属无选择余地）。
>
> **口径统一（P0#2）**：`s1_xml` ground 与 S2 运行时同用 `classify_image_type(caption, note, image_path)`
> （`image_path = data.xml.parent/fileref`，同一解析基准），消除"ground 用关键词、运行时用像素"的分叉。
> `verify_s2_color_classifier.py` 同步同一组合规则。

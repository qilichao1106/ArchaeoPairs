## 必须实现

### 1. 命名 `src/archaeopairs/naming.py`

- `extract_fig_number(caption: str | None, fallback: str = "图") -> str`：
  - 支持 `图2-1-16`、`图七`、`图二六`、`图版204`、`拓片三七`；保留字母/数字后缀（`图七a`、`图2-1-16b`）；剔除图号后的描述汉字。
- `path_artifact(artifact_id: str) -> str`：冒号 `:：∶` → `-`。
- `build_image_name(fig_number: str, seq: str | None, artifact_id: str) -> str`：
  - `原图名_[seq|01]_器物号.png`；`seq=None` → `01`；多序号用逗号串（调用方传入）。
- `dedup_name(name: str, registry: dict[str, int]) -> str`：同名追加 `_1`、`_2`，插在扩展名前；registry 由调用方 book 级共享。

### 2. 成图 `src/archaeopairs/compose/render.py`

```python
class ComposeConfig:
    margin_pct: float = 0.03
    min_margin: int = 6

def compose_unit(image_bgr, unit, views: dict[int, View],
                 scales: dict[int, ScaleBar], cfg=None) -> tuple[np.ndarray, dict]:
    ...
```

- `unit` 为 `ArtifactUnit` 或同形 dict；`views`/`scales` 按 id 索引。
- 内容掩膜：
  - `unit.whole_image=True` → 全图像素为内容；
  - 否则并集 `views[view_id].mask_rle` 解码掩膜；无 view/空掩膜 → `ComposeError`。
- 画布：纯白 `255`；内容紧致 bbox；`margin = max(cfg.min_margin, round(cfg.margin_pct * max(cw,ch)))`。
- **纯平移**：内容像素按原坐标贴到 `margin` 偏移处；不缩放、不旋转、不重排；`pixel_mismatch=0`（逐像素自检）。
- 比例尺：对 `unit.scale_bindings` 的每个 `scale_id`，从 `scales[scale_id].bbox` 裁原图像素，按原顺序水平排列在内容下方、居中；共享尺按绑定列表重复。
- 返回 `(canvas_bgr, meta)`；`meta` 含 `canvas_size/content_box/content_paste_at/margin/pixel_mismatch/scales`。
- 无比例尺不报错（`no_scale` 由上层标记）；找不到 scale_id 记入 `meta["missing_scales"]`，不静默崩溃。

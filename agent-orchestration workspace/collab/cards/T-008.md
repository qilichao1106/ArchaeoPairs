## 必须实现

### 1. 模型 `src/archaeopairs/models.py`

```python
class ScaleBinding(BaseModel):
    scale_id: int
    source: str          # L1_prefix | L2_unique_shared | L3_vl | unknown
    shared: bool = False
    text: str = ""
    value: float | None = None
    unit: str | None = None
    prefix_nos: list[str] = []
```

### 2. 绑定 `src/archaeopairs/mapping/scales.py`

```python
def bind_scales(groups: list[ViewGroup], scales: list[ScaleBar]) -> tuple[
    list[list[ScaleBinding]], list[dict], list[str]
]:
    ...  # (bindings_by_group, scale_records, alarms)
```

规则：

- **L1 前缀硬绑**：`ScaleBar.prefix_nos` 与 `ViewGroup.seq_ids` 有交集 → 绑定该组；`source="L1_prefix"`；`shared = len(prefix_nos)>1 or len(group.seq_ids)>1`。
  - 一把尺可绑定多个组（组标签），每个组各记一份。
- **L2 唯一尺共享**：全图恰好 1 把尺，且没有 L1 绑定 → 绑定到所有尚无尺的组；`source="L2_unique_shared"`，`shared=True`。
- **L3 多尺无前缀**：≥2 把尺且某尺无 `prefix_nos` → 该尺不绑定，`scale_records[si]["abandoned"]=True`，alarm `E004`；禁止按坐标距离推断。
- **组无尺**：任一组无任何绑定 → alarm `E007`，并在 `scale_records` 或返回 conflicts 中记录 `group_no_scale:<group_id>`；不得静默。
- `scale_records` 每把尺一条：`scale_id/text/bbox/value/unit/prefix_nos/abandoned/source`。

### 3. Unit 应用 `src/archaeopairs/mapping/scales.py`

```python

                         bindings_by_group: list[list[ScaleBinding]]) -> ArtifactMap
```

- 对每个 Unit，按 `group_ids` 并集其绑定；去重按 `scale_id`。
- `unit.scale_bindings = [b.model_dump() for b in bindings]`。
- Unit 无任何尺 → `unit.status="review"`，`amap.conflicts` 增加 `group_no_scale:<group_id>`；不删除 Unit。
- 返回新 `ArtifactMap`（不修改输入对象）。

### 4. 导出 `src/archaeopairs/mapping/__init__.py`

导出 `ScaleBinding`、`bind_scales`、`apply_scale_bindings`。

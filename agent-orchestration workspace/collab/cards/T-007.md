## 必须实现

### 1. 模型 `src/archaeopairs/models.py`

```python
class ViewBinding(BaseModel):
    view_id: int
    seq_id: str | None
    method: str          # inside | smallest_containing | unbound
    confidence: float = 1.0

class ViewGroup(BaseModel):
    group_id: int
    view_ids: list[int]
    seq_ids: list[str]
    evidence: dict = {}

class ArtifactUnit(BaseModel):
    artifact_id: str
    artifact_name: str | None = None
    seq_ids: list[str] = []
    view_ids: list[int] = []
    group_ids: list[int] = []
    scale_bindings: list[dict] = []
    line: str = "multi_line"
    case: str | None = None
    source: str = "figure_note"
    confidence: float = 0.0
    whole_image: bool = False
    status: str = "output"
    evidence: dict = {}

class ArtifactMap(BaseModel):
    book_id: str
    figure_id: str
    line: str = "multi_line"
    case_type: str | None = None
    units: list[ArtifactUnit] = []
    unbound_groups: list[dict] = []
    unbound_views: list[dict] = []
    unbound_seqs: list[dict] = []
    conflicts: list[str] = []
    alarms: list[str] = []
    status: str = "composed"
```

### 2. 绑定与归组 `src/archaeopairs/mapping/views.py`

- `normalize_seq_label(text: str) -> str | None`：`"1."`/`"1、"`/`"1"`/`"①"` → `"1"`；`"2、3"` 等组标签不是单序号，返回 None（由组标签解析器处理）。
- `bind_labels_to_views(views: list[View], seq_labels: list[SeqLabel]) -> list[ViewBinding]`：
  - 每个序号取 bbox 中心；
  - 找到 bbox 包含中心的视图；多个时取**面积最小**的视图；无包含 → `unbound`；
  - 一个视图可绑定多个序号（组标签）；返回每个 (view, seq) 一条；
  - 不猜测、不按距离硬配。
- `group_views(views, bindings, *, all_unlabeled_rule_b=False) -> tuple[list[ViewGroup], list[dict]]`：
  - 同一 `seq_id` 的所有视图 → 一个组；
  - 无绑定视图 → `unbound_views`；若 `all_unlabeled_rule_b=True` 且全图无标签 → 所有视图组成一个 `seq_ids=[]` 的组；
  - `view_id` 按阅读序 0..N-1（沿用输入顺序）。

### 3. 组装 ArtifactMap `src/archaeopairs/mapping/views.py`

`build_artifact_map(views, bindings, text_mapping, *, book_id, figure_id, line="multi_line", all_unlabeled_rule_b=False) -> ArtifactMap`

- 先 `group_views`。
- 对每个组：
  - `seq_ids` 来自组；arts = `text_mapping.seq_to_artifacts` 中这些 seq 的并集（去重，保持顺序）；
  - 无 arts → `unbound_groups`；
  - 1 seq : N art → N 个 Unit，`view_ids` 共享；
  - N seq : 1 art / N seq : N art → 每个 art 一个 Unit；`view_ids` 取声明该 art 的组的视图；
  - 同一 artifact 出现在多个组：
    - 若各组都只声明该 artifact → 合并为一个 Unit（view_ids/seq_ids 并集）；
    - 否则登记 `cross_group_artifact:<id>` 冲突，保留多 Unit 不猜测。
  - 组标签 `seq_ids=[]`（rule B 无序号）：若有 `text_mapping.caption_artifacts` 且唯一 → 一个 Unit；多个 → 冲突；无 → unbound。
- `unbound_seqs`：`text_mapping.seq_to_artifacts` 中没有任何组声明的 seq。
- `unbound_views`：未绑定且未进入 rule B 组的视图。
- `conflicts` 合并 `text_mapping.conflicts`、跨组冲突、captions 多号冲突。
- `case_type` 取 `text_mapping.case_type`；`status`：有 units 且无 conflicts/alarms → `composed`，否则 `pending_review`（E002/E005 等由上层另行添加）。
- 不绑定比例尺（`scale_bindings=[]`），留 T-008。

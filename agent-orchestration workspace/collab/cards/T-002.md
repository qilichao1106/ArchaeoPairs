## 必须实现

### 1. 数据模型 `src/archaeopairs/models.py`

```python
class ImageType(str, Enum):  # 五分类
    SINGLE_LINE = "single_line_artifact"
    MULTI_LINE = "multi_line_artifact"
    SINGLE_PLATE = "single_plate_artifact"
    MULTI_PLATE = "multi_plate_artifact"
    DISCARDED = "discarded"

class WorkLine(str, Enum):
    MULTI_LINE = "multi_line"
    SINGLE_LINE = "single_line"
    SINGLE_PLATE = "single_plate"
    ARCHIVE = "archive"

class FigureInput(BaseModel):
    book_id: str
    figure_id: str
    fileref: str
    media_path: str
    caption: str | None
    figure_note: str | None
    body_paras: list[dict]   # [{"id": "p1", "text": "..."}]
```

### 2. XML 摄入 `src/archaeopairs/ingest/xml.py`

`parse_book(xml_path: str | Path, book_id: str, media_root: str | Path | None = None) -> list[FigureInput]`

- 命名空间无关（按 local tag name 匹配）。
- 只取 `figure` 的直接子节点 `figure-title` / `figure-note`；多个 note 用换行合并。
- `imagedata@fileref` 取媒体相对路径；`media_path` = `media_root/fileref`（未给 media_root 时用 XML 所在目录）。
- 无 `imagedata` 的 figure 跳过。
- `figure_id = f"{book_id}:{Path(fileref).stem}"`。
- 正文段落：收集 XML 中所有 `para` 文本，排除空文本；`id` 用 `p1`、`p2`… 顺序编号。
- 不猜测缺失图题/图注：`caption`/`figure_note` 允许 None。

### 3. 器物号计数 `src/archaeopairs/classify/image_type.py`

`count_artifacts(caption: str | None, figure_note: str | None) -> int`

- 器物号形态：`M4:6`、`2004CWWM11：5`、`M43:75a`、`M39:8-1`、`00FBH1:6`；冒号全角/半角/ratio 冒号归一。
- 保留后缀字母与 `-N` 子编号（不同后缀算不同器物）。
- 图注有器物号时只用图注；图注无号时回退图题；去重后计数。
- 不把比例尺文本（`0 8厘米`）、图号（`图二一二`）计入。

### 4. 五分类 `src/archaeopairs/classify/image_type.py`

`classify_image_type(caption, figure_note, image_path) -> ImageType`

- N=0 → discarded。
- 线/彩家族：Pillow 打开，最长边缩到 96px，numpy 统计：
  - 通道极差 `pct20 = (d>20).mean()*100`、`mean_chroma = d.mean()`；
  - 彩色：`pct20>=5` 或 (`mean_chroma>=8` 且 `pct20>=1`)；
  - 否则 `mid = L∈(64,192) 占比`，`mid>=15` → gray（照片），否则 line。
- 拓图词 `拓片|拓本|拓印|线描|摹写`：gray + 拓图词 → line；color 不被覆盖。
- 图像不可读/缺失：回退关键词 `图版|圖版`；拓图词 → line；否则有图版词 → plate，无图版词 → line。
- N==1 → single_line/single_plate；N>=2 → multi_line/multi_plate。

`work_line_of(image_type) -> WorkLine`：
- single_line→single_line；single_plate→single_plate；multi_line→multi_line；multi_plate/discarded→archive。

`classify(caption, figure_note, image_path) -> tuple[ImageType, WorkLine]` 便捷函数。

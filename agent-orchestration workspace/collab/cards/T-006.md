## 必须实现

### 1. View 模型 `src/archaeopairs/models.py`

```python
class View(BaseModel):
    view_id: int
    bbox: BBox                 # (x0, y0, x1, y1)，右下开区间
    area: int
    mask_rle: str              # COCO 风格列主序 RLE
    incomplete: bool = False
```

### 2. RLE `src/archaeopairs/vision/rle.py`

- `rle_encode(mask: np.ndarray) -> str`：bool 掩膜 → `"{h}x{w}:{counts}"`，列主序、首行程背景。
- `rle_decode(rle: str) -> np.ndarray`：严格 round-trip；总长不符抛 `ValueError`。
- 不引 pycocotools。

### 3. 分割 `src/archaeopairs/vision/seg.py`

- `load_image(path) -> np.ndarray`：用 `np.fromfile + cv2.imdecode`，Windows 中文路径安全；不可读抛 `OSError`。
- `extract_contours(gray, dilate_k=5, min_area=15.0) -> (kept, removed, binary)`：
  - OTSU 反相二值化 → 形态学膨胀 → `findContours(RETR_CCOMP)`；
  - 剔除孔洞（有父轮廓）与四角均落在更大轮廓内的包含轮廓；
  - 轨迹按阅读序（上→下、左→右）排序；
  - 元素含 `bbox/area/contour/hole`。
- `segment_views(image_path, *, dilate_k=5, min_area=15.0) -> list[View]`：
  - 对每个 kept 轮廓填充掩膜（`filled_mask`），RLE 化；
  - `view_id` 按阅读序 0..N-1；
  - `incomplete=False`；
  - 纯白图 → 空列表；
  - 禁 bbox 矩形切割、禁像素补全。
- `filled_mask(contour, shape) -> np.ndarray`、`mask_iou(a,b) -> float`。

### 4. 导出 `src/archaeopairs/vision/__init__.py`

导出 `load_image`、`extract_contours`、`segment_views`、`filled_mask`、`mask_iou`、`rle_encode`、`rle_decode`、`View`。

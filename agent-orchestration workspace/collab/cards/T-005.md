## 必须实现

### 1. PaddleOCR 适配器 `src/archaeopairs/ocr/paddle.py`

- `PaddleOCRProvider(engine=None, lang="ch")` 实现 `OCRProvider`。
- `engine=None` 时懒加载 `paddleocr.PaddleOCR`；导入/初始化失败 → `PaddleUnavailableError`（不得静默返回空结果）。
- `read(image_path)`：
  - 优先 `engine.predict(str(path))`；否则兼容 `engine.ocr(str(path))`。
  - 兼容 PaddleOCR 3.x 结果（`rec_texts` / `rec_scores` / `rec_polys` 或 `dt_polys`），也兼容旧式 `[[box, (text, score)], ...]`。
  - 输出 `OcrResult(source="paddle")`：
    - 纯数字/序号形态 → `seqs`；
    - 含 `厘米|cm|mm|毫米` 且带数字 → `scales`（`value` 尽量解析）；
    - 其余 → `texts`。
  - bbox 为轴对齐 `[x0,y0,x1,y1]`（四点多边形取 min/max）。
- 空结果合法（无文字），异常 → `OcrError`。

### 2. Hybrid OCR `src/archaeopairs/ocr/hybrid.py`

- `HybridOCRProvider(primary: OCRProvider, secondary: OCRProvider)`。
- `read`：依次调用两个 provider。
  - 两者都成功 → `merge_ocr_results(primary, secondary)`；`source="hybrid"`。
  - 一个失败 → 返回另一个结果，`raw["degraded"]` 记录失败方与异常类型；不抛错。
  - 两者都失败 → `OcrError`（汇总两个异常类型）。
- 默认组合示例：`HybridOCRProvider(VlmOCRProvider(client), PaddleOCRProvider())`。

### 3. 导出 `src/archaeopairs/ocr/__init__.py`

导出 `OCRProvider`、`OcrError`、`PaddleOCRProvider`、`PaddleUnavailableError`、`HybridOCRProvider`、`VlmOCRProvider`、`merge_ocr_results`。

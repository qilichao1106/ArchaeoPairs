## 必须实现

### 1. 模型 `src/archaeopairs/models.py`

- `PairRecord`：与 `contracts/pair_record.schema.json` 对齐：
  `book_id/figure_id/artifact_id/artifact_name/figure_number/source_role/image_path/candidate_images/image_merge_mode/description_text/text_length/provenance/quality_flags/status`。
- `FigureResult`：`book_id/figure_id/image_type/work_line/status/pairs/artifact_map/alarms/conflicts/exclude_reason`。

### 2. 管线 `src/archaeopairs/pipeline.py`

```python
class Writer(Protocol):
    def write_image(self, name: str, image: np.ndarray) -> str: ...
    def write_pairs(self, records: list[dict]) -> None: ...
    def write_ledger(self, rows: list[dict]) -> None: ...

class NullWriter: ...  # write_image 返回 name，其余 no-op

class PipelineConfig:
    ocr: OCRProvider | None = None
    writer: Writer | None = None
    name_registry: dict[str, int] | None = None
    vlm_client: VlmClient | None = None
    paddle_engine: object | None = None

def process_figure(fig: FigureInput, cfg: PipelineConfig) -> FigureResult
def process_book(figures: list[FigureInput], cfg: PipelineConfig) -> list[FigureResult]
```

- `ocr` 为 None 时默认 `HybridOCRProvider(VlmOCRProvider(VlmClient()), PaddleOCRProvider(cfg.paddle_engine))`；测试必须注入 fake。
- **L1**：
  1. `parse_note(fig.figure_note)`、`extract_caption_artifacts(fig.caption)`、`split_body(fig.body_paras)`、`build_text_mapping`。
  2. `segment_views(fig.media_path)`；`ocr.read(fig.media_path)`。
  3. `bind_labels_to_views` → `group_views` → `build_artifact_map`。
  4. `bind_scales(groups, ocr.scales)` → `apply_scale_bindings`。
  5. 加载 BGR（`vision.load_image`），对每个 Unit `compose_unit`。
  6. 命名：图号 `extract_fig_number(caption, fallback=Path(fileref).stem)`；seq_tag 单号或逗号串；`build_image_name` + `dedup_name`。
  7. PairRecord：`source_role="line"`、`image_merge_mode="line_only"`；描述取 `TextArtifact` 映射（无则 None + `no_text`）；`provenance.mapping` 含 artifact_id/seq_ids/view_ids/scale_ids/scale_sources/confidence/line/source_role；无尺加 `no_scale`；>2000 字加 `long_text`；共享视图加 `shared_image`。
  8. `writer.write_image`；ledger 行含 book/figure/artifact/seq/view/scale/status。
  9. 状态：有 Pair 且无 alarms/conflicts → `output`；否则 `pending_review`。
- **L2/L3**：
  - 解析唯一 artifact：图注 > 图题 > 正文（复用 T-003 结果）；0 个 → pending_review；>1 → E005 pending。
  - 构建 `ArtifactUnit(whole_image=True, scale_bindings=[])`，`compose_unit` 整图；PairRecord `source_role=line|plate`、`image_merge_mode=line_only|plate_only`，`no_scale`。
- **L4**：`EXCLUDED`，无 Pair。
- `process_book`：对每个 Figure 调用，最后 `writer.write_pairs` 与 `writer.write_ledger`；异常不中断整批，记 `status="failed"`。

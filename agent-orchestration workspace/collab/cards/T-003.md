## 必须实现

### 1. 器物号工具 `src/archaeopairs/text/artifact_id.py`

- `normalize_artifact_id(raw: str) -> str`：冒号 `:：∶` → `:`，折叠冒号旁空白；保留大小写、后缀字母 `75a`、`-N` 子编号 `8-1`；圈号等非器物号不处理。
- `extract_artifacts(text: str) -> list[str]`：按出现顺序抽取器物号并去重；支持 `M4:6`、`2004CWWM11：5`、`M43:75a`、`M39:8-1`、`00FBH1:6`、`Bb9`（无冒号的前缀号只在括号内条目文本中作为名称证据，不单独产生 artifact_id，除非形如 `X:数字`）。
- 不把 `0 8厘米`、`图二一二`、`图2-1-16` 当器物号。

### 2. 图注解析 `src/archaeopairs/text/note.py`

模型（加到 `models.py`）：

```python
class NoteItem(BaseModel):
    seq: str                      # 原文序号片段，如 "1、2" / "1～4、6" / "A"
    seq_list: list[int]           # 展开后的序号；字母序号可空
    name: str | None
    artifact_ids: list[str]
```

`parse_note(text: str) -> list[NoteItem]` 覆盖需求 §5.6 的实测语法：

- `1.骨笄` / `1. 陶豆 2. 陶壶`
- `1. 骨笄（M4:1）` / `1、2. 陶豆（M4:2、M4:1）`
- `1～4.豆（M3：4、M3：2、M3：3、M3：1）`
- `2、9.铁器（00FBH1:6、00FBH1:3）`
- `A. 盗坑（长沙青振）`（字母序号，seq_list 可为空）
- `$1\sim 4$ 陶豆 5.陶壶` / `1.00FBG1:2` 无空格
- `3～7. 陶豆`（无 artifact_id，允许空列表）
- `0 8厘米` 纯比例尺噪声 → 不产生条目
- `①` → 1；`1、2.`、`3～5、9.` 组列/范围展开
- 同一图注多个 note 段由调用方换行合并后解析。

`extract_caption_artifacts(caption: str | None) -> list[str]`：从图题括号/文本中抽器物号，作为图注无号时的弱兜底。

### 3. 正文切分入口 `src/archaeopairs/text/body.py`

模型（加到 `models.py`）：

```python
class TextArtifact(BaseModel):
    artifact_id: str
    text: str
    source_para_ids: list[str]
    markers: list[str]      # ["single_anchor" | "multi_anchor" | "no_anchor" | ...]
```

`split_body(paras: list[tuple[str, str] | dict]) -> list[TextArtifact]`

- 按 `artifact_id` 锚点切分；单锚点整段归属；多锚点按 `标本X:1，……` 边界切分。
- 无锚点段挂最近上文锚点，`markers=["no_anchor"]`；无法归属的段丢弃并记录 marker。
- 不做 LLM 确认。

### 4. 文本映射 `src/archaeopairs/mapping/text_map.py`

模型：

```python
class TextMapping(BaseModel):
    seq_to_artifacts: dict[str, list[str]]
    caption_artifacts: list[str]
    case_type: str            # rule_a | rule_b | split_same_seq | range_split | seq_missing
    conflicts: list[str]
```

`build_text_mapping(note_items, caption_artifacts, text_artifacts) -> TextMapping`

- 图注优先；图注无器物号时用图题兜底；两者都无 → `seq_missing`（degraded）。
- 基数：
  - 1 seq : N art → 每个 art 都挂在该 seq；
  - N seq : 1 art → 同一 art 挂到每个 seq（rule_b）；
  - N seq : N art → 位置对应 zip；
  - 数量不一致 → conflict，不猜测。
- `case_type`：rule_a / rule_b / split_same_seq / range_split / seq_missing。
- 不做笛卡尔积。

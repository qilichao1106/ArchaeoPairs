## 必须实现

### 1. 文件 Writer `src/archaeopairs/output/writer.py`

```python
class FileWriter:
    def __init__(self, out_dir: str | Path) -> None: ...
    def write_image(self, name: str, image: np.ndarray) -> str: ...
    def write_pairs(self, records: list[dict]) -> None: ...
    def write_ledger(self, rows: list[dict]) -> None: ...
```

- `out_dir` 不存在则创建。
- 图片写 `out_dir/pairs/<name>`：BGR ndarray → PNG；`cv2.imencode + Path.write_bytes`，Windows 中文路径安全。
- `write_pairs` 写 `out_dir/pairs.jsonl`（UTF-8，每行一个 Pair，覆盖写）。
- `write_ledger` 写 `out_dir/ledger.jsonl`（UTF-8，每行一条，覆盖写）。
- 返回图片相对 `out_dir` 的路径或绝对路径，保持一致；写失败抛 `OSError`。
- 不静默丢记录；空列表也写空文件。

### 2. CLI `src/archaeopairs/cli.py`

```python
def default_ocr(*, vl: bool = True): ...
def run_book(book, books_dir="books", media_root=None, limit=None,
             out_dir="out", ocr=None, vl=True) -> dict: ...
def run_books(books_dir="books", media_root=None, limit=None,
              out_dir="out", ocr=None, vl=True) -> dict: ...
def main(argv: list[str] | None = None) -> int: ...
```

- `default_ocr(vl=True)`：`HybridOCRProvider(VlmOCRProvider(VlmClient()), PaddleOCRProvider())`；`vl=False` → `PaddleOCRProvider()`。
- `run_book`：
  - 找 `books/<book>/data.xml`；`parse_book(xml, book, media_root)`；`limit` 截断。
  - `PipelineConfig(ocr=ocr or default_ocr(vl=vl), writer=FileWriter(out_dir), name_registry={})`。
  - `process_book`；返回 `{"book","figures","pairs","statuses","outputs"}`。
  - 任何单图失败不中断；汇总 `failed/pending_review/output/excluded` 计数。
- `run_books`：遍历 `books_dir` 下含 `data.xml` 的子目录，汇总。
- `main` argparse：
  - `run-book --book 必填 --books-dir books --media-root --limit N --out out --no-vl`
  - `run-books --books-dir books --media-root --limit N --out out --no-vl`
  - 打印 JSON 摘要；退出码 0 即使有复核项（失败/异常退出码非 0）。
- `pyproject.toml` 加 `[project.scripts] archaeopairs = "archaeopairs.cli:main"`。

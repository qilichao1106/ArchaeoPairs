## 必须冻结的行为（实现见 commit `c4e0639`）

测试只写 `tests/qa/T-012/`，不得改 `src/`；用合成视图/合成 XML/ fake OCR，不联网。

### 1. 字形网格读序号（pipeline）

- `_glyph_candidate_boxes(views, ocr, image_shape)`：
  - 只收 4–60px 的小连通域；
  - 排除中心落在 OCR text（高≤60）或 scale 框内的字形；
  - 排除顶部 3% 图例带；
  - 同一行、水平间距≤6px 的相邻字形合并（多位数）。
- `_read_glyph_labels(ocr, image_path, boxes)`：
  - fake provider 实现 `read_glyphs`，返回 `["1", None, "A"]` → 生成两条 `SeqLabel`；
  - provider 无 `read_glyphs` / 抛异常 / 长度不符 → `[]`，调用方回退整图 OCR seqs。
- 管线：字形标签非空时替换整图 OCR seqs；字形框与视图框完全一致，过滤后不再有字形视图。

### 2. 重复/幻觉序号（pipeline）

- `_sanitize_seq_labels`：同号两条框，一条靠近小字形视图、一条在大绘图内部 → 只保留靠近字形的一条。
- 两条同号框都靠近各自字形 → 都保留（合法的 1:N 多视图）。
- 无字形参考时保留面积最小的一条。

### 3. 文本块不得吞掉绘图（pipeline）

- `_text_owned(大视图, 大文本块)`：仅 75% 以上覆盖才归文本；VLM 把器物误报为 “I” 时绘图保留。
- 小字形视图被文本行覆盖时仍归文本（`_aux_owned` 语义不变）。

### 4. 比例尺框扩到尺线（pipeline）

- 合成图：文字行 “0 4厘米” + 下方横线；OCR bbox 只盖文字。
- `_expand_scale_boxes` 返回 bbox 必须包含横线最后一行，并左右覆盖完整文字；bbox 为 tuple。
- 无横线时保持原 bbox。

### 5. 超大单元保护（pipeline）

- `_oversized_units`：两视图并集占图面积 >70% → 该 artifact_id 入集合。
- 管线中该 unit 状态为 `review`、alarm `unit_oversized:<id>`、不写 PNG；其他 unit 正常输出。

### 6. 器物名称（pipeline）

- L1：图注 “1. 陶鼎（M1:1） 2. 陶盒（M1:2）” → PairRecord.artifact_name 分别为 陶鼎/陶盒。
- L2/L3：唯一器物号命中图注 item → artifact_name 写入；无名称时保持 None。

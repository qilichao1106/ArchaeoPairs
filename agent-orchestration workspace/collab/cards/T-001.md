## 场景

契约已冻结（需求 V1.0）。测试套件只验证 schema 本身，不测流水线行为。

## 必须覆盖

1. `artifact_map.schema.json`、`pair_record.schema.json` 可加载且通过 Draft 2020-12 metaschema 校验。
2. 合法 ArtifactMap 实例通过；缺必填字段（如 `units`）失败。
3. 非法枚举（`line`、`case_type`、`scale_bindings[].source`）失败。
4. 合法 PairRecord 通过；`description_text=null` 与 `quality_flags=["long_text"]` 合法。
5. PairRecord 缺 `artifact_id` / `mapping` 失败。
6. `artifact_map` 的 `alarms` 枚举恰为 E001–E007。
7. 至少一条负向对照：把合法实例改坏，断言校验失败（不是 `assert 1==2`）。

## 约束

- 只读 `contracts/`；测试文件放 `tests/contracts/`。
- 依赖：pytest + jsonschema（本机已装）。
- 工作目录为项目根；测试内用 `Path(__file__).resolve().parents[2]` 定位仓库根。
- 完成后运行 `python -m pytest tests/contracts -q`，记录真实 `N passed`。
- 不提交、不合并；变更留工作区，由 Orchestrator 代提交。

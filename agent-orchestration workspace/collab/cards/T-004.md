## 必须实现

### 1. 模型 `src/archaeopairs/models.py`

```python
class SeqLabel(BaseModel):
    text: str
    bbox: tuple[int, int, int, int]
    conf: float | None = None

class ScaleBar(BaseModel):
    text: str
    bbox: tuple[int, int, int, int]
    value: float | None = None
    unit: str | None = None
    prefix_nos: list[str] = []

class TextBlock(BaseModel):
    text: str
    bbox: tuple[int, int, int, int]

class OcrResult(BaseModel):
    seqs: list[SeqLabel] = []
    scales: list[ScaleBar] = []
    texts: list[TextBlock] = []
    source: str = "unknown"     # vlm | paddle | hybrid
    raw: dict = {}
```

### 2. VLM 客户端 `src/archaeopairs/vlm/client.py`

`VlmClient`：
- 默认 `base_url` 来自 `DASHSCOPE_BASE_URL`，缺省 `https://llm-1pxqd38dwq24f1gn.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`。
- 默认 `model="deepseek-v4.1-flash-1017"`；密钥 `DASHSCOPE_API_KEY`（构造参数可覆盖）。
- `chat(messages: list[dict], *, json_mode=False, timeout=60, max_retries=2) -> str`：POST `{base_url}/chat/completions`，Bearer 鉴权；429/5xx 指数退避重试；超时/4xx 抛 `VlmError`；缺 key 抛 `VlmUnavailableError`。
- `describe_image(image_path, prompt, *, json_mode=True) -> str`：图片转 base64，message content 为 `[{"type":"text","text":prompt},{"type":"image_url","image_url":{"url":"data:image/png;base64,..."}}]`。
- `last_usage: dict`、`last_latency_ms: float` 记录 usage/耗时；禁止在日志/异常中打印密钥。
- 使用 `httpx`（加入 pyproject dependencies）。

### 3. Prompts `src/archaeopairs/vlm/prompts.py`

- `OCR_PROMPT`：要求只返回 JSON：
  `{"seqs":[{"text":"1","bbox":[x0,y0,x1,y1],"conf":0.9}],"scales":[{"text":"0 8厘米","bbox":[...],"value":8,"unit":"厘米","prefix_nos":["1","2"]}],"texts":[{"text":"盖顶面纹饰","bbox":[...]}]}`
- `VISUAL_PROMPT`：图类/视图关系/分割与比例尺校验，返回结构化 JSON。
- `QC_PROMPT`：缺陷列表与 verdict，返回结构化 JSON。
- 提示词明确：不得猜测；不确定项返回空数组或 `null`。

### 4. OCR 接口 `src/archaeopairs/ocr/base.py`

- `OCRProvider` Protocol：`read(image_path: str | Path) -> OcrResult`。
- `merge_ocr_results(primary, secondary) -> OcrResult`：按文本+bbox 去重合并；同文本不同 bbox 保留两条并在 `raw["conflicts"]` 记录；`source="hybrid"`。

### 5. VLM OCR `src/archaeopairs/ocr/vlm.py`

- `VlmOCRProvider(client: VlmClient)` 实现 `OCRProvider`。
- `read` 调用 `describe_image(..., OCR_PROMPT, json_mode=True)`，解析 JSON 为 `OcrResult(source="vlm", raw=parsed)`。
- JSON 非法、bbox 非 4 元组、必需字段缺失 → `OcrError`（不得静默返回空结果）。
- 空图/无文本 → 合法空 `OcrResult`。

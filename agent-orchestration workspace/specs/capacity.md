## 运行方式

```bash
python "agent-orchestration workspace/中间过程数据和脚本/batch_books.py" --workers 2 --exclude 万州瓦子坪
python -m archaeopairs.cli run-book --book 万州瓦子坪 --out runs/book_wanzhou
```

- 每本一个子进程；已有 `pairs.jsonl` 的书跳过，可断点续跑。
- 单本 L1 占比高（如师宗上 159 图）时 wall time 以该本为准。
- 批跑完成后用 `audit_batch.py` / `review_report.py` 出缺口清单。

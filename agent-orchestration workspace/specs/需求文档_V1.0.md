## 0. 术语

| 术语 | 含义 |
|---|---|
| 器物号 `artifact_id` | 报告内唯一标识器物的编号，如 `M4:6`、`2004CWWM11:5`；命名空间为 `book_id` |
| 图中序号 `seq_id` | 图内局部编号（`1.`、`2`、`2、3.`、`1～4`），仅用于图面匹配与分组 |
| 视图 `view` | 分割得到的一个原子线图连通域（含其掩膜） |
| 组 `group` | 同一器物或同一序号对应的视图集合 |
| 单元 `Unit` | 映射表中的一行 = 一件器物 = 一张图 = 一个 Pair |
| Pair | 一条样本：`artifact_id + image + description_text` |
| 规则 A | 多器物图：图注有序号列表，序号与线图硬匹配 |
| 规则 B | 单器物多视图图：多个视图同属一个器物号，合并为一张图 |
| L1/L2/L3/L4 | 四条工作线：多器物线图 / 单器物线图 / 单器物版图 / 其它不处理 |
| 比例尺三级 | L1 序号硬匹配 > L2 全图唯一共享 > L3 VL 兜底 > 失败报警 |

## 1. 目标与非目标

### 1.1 目标

- 从 17 本考古报告的结构化 XML 与图版像素中，为**单件器物**构造 Pair。
- 只处理四条工作线；每条线有明确输入、输出和失败去向。
- 建立并落盘"器物 ↔ 图中序号 ↔ 器物号"映射，支持审计与人工复核。
- 产出可复跑、可断点续跑、可回归的数据集。

### 1.2 非目标

- 多器物彩图拆分（`multi_plate_artifact` 仅归档）。
- 跨图、跨章节、跨报告的同一器物合并。
- 自动猜测缺失映射、自动补全掩膜像素、用 bbox 代替掩膜切割。
- 自动修正回环（VLM 只做仲裁/质检，不做自动修复）。
- 复核 UI、调度平台、消息队列（复核工具细节后置）。

### 1.3 成功标准（高层）

- 四条工作线路由 100% 正确，L4 零 Pair。
- 每个已绑定序号要么进入 Unit，要么进入 `unbound_*`，无静默丢弃。
- 一器物一 Unit 一图一 Pair（同一序号多器物共享图像的显式例外除外）。
- 每个 Unit 的比例尺绑定都有来源（L1/L2/L3）。
- 黄金集上的映射准确率达到约定阈值（见 §8）。

## 2. 输入契约

### 2.1 目录与格式

- **R-IN-01**：规范输入为 `books/<book>/data.xml` + `books/<book>/media/`；`imagedata@fileref` 相对书目录解析。
- **R-IN-02**：允许 `--media-root` 覆盖媒体根目录，用于图片外置；覆盖后仍保持"书目录 + media"语义。
- **R-IN-03**：XML 必须为 DocBook 结构，图题使用 `role="figure-title"`，图注使用 `role="figure-note"`；编码 UTF-8。
- **R-IN-04**：`figure-note` 允许整图缺失；`figure-title` 优先从 XML 获取，缺失时用文件名/图版号降级并标记 `degraded`。
- **R-IN-05**：媒体文件缺失、损坏或不可解码 → 该 figure 排除，写违约报告；不做像素修复。
- **R-IN-06**：默认一张 media 对应一张 figure；一图多 figure 或拼版图**不自动裁切**。图注器物数与画面独立物件数明显不一致 → 标记 `multi_panel`，转复核/归档；L3 仅在画面确为单一物件时成立。
- **R-IN-07**：图号支持 `图2-1-16`、`图七`、`图二六`、`图七a`、`图2-1-16b`、`图版N`、`拓片N` 等实测形态；字母/数字子编号完整保留。
- **R-IN-08**：所有器物号以 `book_id` 为命名空间；不跨书合并、不依赖全局唯一。
- **R-IN-09**：输入图像可为彩色/灰度/线图/拓图；允许纵向排版，处理时统一旋转至横向；不要求上游提供 OCR。
- **R-IN-10**：上游结构化违约（角色缺失、图注节点错位）记入违约清单；可降级继续的不得静默失败。

### 2.2 页面与图类

- **R-IN-11**：图片五分类 → 四条工作线：`multi_line_artifact`→L1；`single_line_artifact`→L2；`single_plate_artifact`→L3；`multi_plate_artifact`/`discarded`→L4。
- **R-IN-12**：类型判定以 XML 器物号个数为一级证据，像素统计判线/彩家族；无器物号且无可信信号 → L4 归档。
- **R-IN-13**：图题含"地层/遗迹"等关键词但画面为独立器物线图的（如地层出土帽钉），按类型 A 进入 L1。
- **R-IN-14**：场景照、墓葬全景、平面图、无器物号插图 → L4，不产出 Pair。

## 3. 对象与映射模型

### 3.1 器物身份

- **R-ID-01**：`artifact_id` 仅指器物号；图版条目号、标本号只作为映射证据，不直接作为 `artifact_id`。
- **R-ID-02**：器物号归一规则：冒号（`:`、`：`、`∶`）统一为半角冒号用于内部键，输出文件名统一为连字符；全角/半角数字、圈号（①→1）归一；大小写保留。
- **R-ID-03**：成分号/前缀号按完整前缀解析，如 `M4-1:2` 的 `M4-1` 是一个完整前缀，不拆成 `M4` 与 `1`；`00FBH1:6`、`ZhB2:7` 同类。
- **R-ID-04**：同一器物号在一张图内出现多次 → 视为同一器物（多视图）；跨图出现 → 各自成 Pair，不合并。
- **R-ID-05**：无器物号的图 → L4 归档；有图无号但正文可反推出唯一器物号 → 允许降级映射并标记。
- **R-ID-06**：器物号末尾的字母后缀（`M43:75a`、`M43:75b`、`M43:75c`）默认保留为**独立器物号**；`-N` 子编号（`M39:8-1`、`M39:8-2`）同理。仅当正文/图注明确说明是同一件器物的不同视图时才归并。例：正文"铁削 3件。标本M43：75a……75b……75c" → 三个独立器物，不得归一为 `M43:75`。

### 3.2 图中序号

- **R-SEQ-01**：`seq_id` 是图内局部编号，支持单号、组列（`2、3.`）、区间（`1～4`）、圈号、字母序号（`A.`）。
- **R-SEQ-02**：序号匹配只认 OCR 文本完全一致（归一后），严禁坐标距离推断。
- **R-SEQ-03**：序号绑定到视图时可使用空间归属（序号标注落在哪个视图附近），但"序号属于哪个器物"只由图注/图题/正文的文本映射决定。

### 3.3 映射关系

- **R-MAP-01**：文本映射优先级：图注 > 图题（弱链，置信 ×0.8）> 正文引用；三源冲突 → 复核，不猜测。
- **R-MAP-02**：必须支持四类基数：
  - 1 seq : 1 art（规则 A 常态）；
  - N seq : 1 art（规则 B 同器多视图，合并为一 Unit）；
  - 1 seq : N art（同号拆，多个 Unit 共享同一图像资产）；
  - N seq : N art（区间拆/组列，按位置对应逐号拆）。
- **R-MAP-03**：禁止笛卡尔积配对；数量不一致时登记冲突，不猜测。
- **R-MAP-04**：映射置信度 <0.7、链冲突、图注与图面序号不一致 → 进入复核。
- **R-MAP-05**：未映射项必须进入 `unbound_groups` / `unbound_views` / `unbound_seqs`，不得静默丢弃。
- **R-MAP-06**：同一器物号跨组的视图，仅当两组映射到**同一单元素器物号集合**时合并；否则登记 `cross_group_artifact` 冲突并复核。
- **R-MAP-07a（N seq : 1 art）**：同一器物号下的多个视图合并为一个 Unit、一张组合图；例 `4、6、7. 串珠（M1:29）`。
- **R-MAP-07b（1 seq : N art）**：
  - 组内视图构成一张组合图 → N 个 Unit **共享同一图像资产**（`image_path` 相同，`provenance.shared_group` 标记），例 `8. 铜釜（M139：3）和铁三足支架（M139：26）`；
  - 组内有 N 个可分离视图且有显式对应证据（子标号/正文）→ 一视图一器物；
  - 数量/顺序证据不足 → 复核，不猜测。
- **R-MAP-07c（N seq : N art）**：按序号位置对应逐号拆，每器物独立成图；例 `1、2. 陶豆（M4：2、M4：1）`。
- **R-MAP-08**：规则 B 无序号整图归属 → 一个 Unit；命名序号段用 `01`；有多个序号时用序号串（如 `2,3`）。

### 3.4 映射台账

- **R-LEDGER-01**：每个 Unit 至少包含：`book_id`、`figure_id`、`artifact_id`、`seq_ids`、`view_ids`、`group_id`、`scale_ids`、`scale_sources`、`line`、`case_type`、`confidence`、`status`。
- **R-LEDGER-02**：未映射项、冲突、报警必须落台账，字段与 Unit 分离。
- **R-LEDGER-03**：台账可导出 JSONL/CSV，供人工复核与覆盖率统计。

## 4. 四条工作线

### 4.1 L1 多器物线图

**流程**：文本解析 → 分割 → 识别 → 映射 → 组合 → 绑比例尺 → 成图 → 质检。

- **R-L1-01 分割**：输出掩膜视图；严禁 bbox 切割、严禁像素补全；重叠器物只取自身掩膜像素。
- **R-L1-02 序号绑定**：视图与序号按文本一致 + 空间归属绑定；歧义登记，不猜测。
- **R-L1-03 组合**：同序号视图成组；同器物多视图合并；跨组同器物按 R-MAP-06 处理。
- **R-L1-04 比例尺**：三级归属：
  - L1：比例尺旁有明确序号/前缀组（`1、2.`、`3～5、9.`、`6～8.`）→ 按序号硬绑；范围展开后逐号绑定；
  - L2：全图仅一个比例尺 → 全局共享，复制给每个 Unit；
  - L3：多尺且部分无号 → VL 读前缀兜底；仍失败 → 报警复核。
  - 正文文字尺寸（如"高11厘米"）不作为图形比例尺的替代；无图形尺按 §5.2 处理。
- **R-L1-05 成图**：每个 Unit 输出一张图；共享比例尺复制；说明文字并入；序号数字剥离（见 §5.2）。
- **R-L1-06 失败去向**：E001–E007 任一 → 复核，不输出 PNG；映射完整、比例尺已绑、自检通过 → 自动输出。

### 4.2 L2 单器物线图

- **R-L2-01**：整图即单一器物，不分割；按图注/图题/正文硬匹配 `artifact_id`。
- **R-L2-02**：命名序号段固定 `01`；成图按整图规格（方向校正/留白）。
- **R-L2-03**：不经 S9 式多器物质检；映射缺失 → 复核。
- **R-L2-04**：无比例尺允许输出，标记 `no_scale`。

### 4.3 L3 单器物版图

- **R-L3-01**：整图即单一器物彩图，不分割；通过器物号/图版条目号→`artifact_id` 映射。
- **R-L3-02**：命名序号段固定 `01`；输出整图。
- **R-L3-03**：无比例尺允许输出，标记 `no_scale`；多器物彩图不进入本线。

### 4.4 L4 其它

- **R-L4-01**：`multi_plate_artifact` / `discarded` 仅归档，记录排除原因；不产出 Unit/Pair。
- **R-L4-02**：L4 不得进入分割、OCR、成图。

## 5. 输出契约

### 5.1 PairRecord

- **R-OUT-01**：Pair 唯一键：`book_id + figure_id + artifact_id`。
- **R-OUT-02**：字段至少包含：`book_id`、`figure_id`、`artifact_id`、`artifact_name`、`figure_number`、`source_role`（line/plate）、`image_path`、`description_text`、`image_merge_mode`、`provenance`、`quality_flags`。
- **R-OUT-03**：`description_text` 取正文中按 `artifact_id` 切分的描述段；可拼接多个段落；图题、图注只作为元数据，不并入描述文本。文本全文保留、不截断；超过 2000 字标记 `long_text` 并转复核（阈值可调）。
- **R-OUT-04**：无描述文本 → 仍输出 Pair，`description_text=null`，`quality_flags=["no_text"]`，并转复核；不得静默丢弃。
- **R-OUT-05**：同一段描述覆盖多个器物 → 允许复制给多个 Pair，`provenance.source_para_ids` 记录来源；不得随意拆分文本。
- **R-OUT-06**：`provenance.mapping` 必须包含 `artifact_id`、`seq_ids`、`view_ids`、`scale_ids`、`scale_sources`、`confidence`、`line`、`source_role`。
- **R-OUT-07**：同一器物跨图的线图/版图**各自成 Pair**，不合并图像；另出 `same_artifact_index.jsonl`（`artifact_id → [line_pair, plate_pair, ...]`）供下游选择。
- **R-OUT-08**：流水线只产通用 PairRecord + JSONL；train/val/test 切分与特定训练格式（如 LLaVA/InternVL）由下游脚本负责，不在流水线内实现。

### 5.2 成图规格

- **R-IMG-01**：PNG；纯白背景（255,255,255）。
- **R-IMG-02**：保留原始像素，不重采样；保留扫描噪点，不做去噪。
- **R-IMG-03**：内容区为原图纯平移，不缩放、不旋转、不重排；逐像素自检通过。
- **R-IMG-04**：四周留白为物体长宽的 2%–5%，不设固定边距。
- **R-IMG-05**：方向统一为横向；纵向图整体旋转，视图/文字/比例尺使用同一旋转矩阵。
- **R-IMG-06**：比例尺必须随器物输出；共享比例尺复制；多比例尺按序号归属；比例尺行置于底部（可居中）。
- **R-IMG-07**：图旁说明文字（如"盖顶面纹饰""主视图"）并入成图；图题/图注不画进像素。
- **R-IMG-08**：序号数字默认剥离，不画进成品图；其 bbox 保留在 provenance 供追溯。
- **R-IMG-09**：L1 无比例尺或无法绑定 → 报警复核；L2/L3 无比例尺允许输出并标记 `no_scale`。
- **R-IMG-10**：同一 `seq` 多器物共享图像资产时，不重复生成内容相同的 PNG；`image_path` 相同、Pair 不同。

#### 5.2.1 比例尺规则（已确认）

- **R-SCALE-01 前缀组硬绑**：比例尺前缀支持 `1、2.`、`3～5、9.`、`6～8.`；范围展开、列表展开，逐号绑定；组内共享同一把尺；来源记 `L1_prefix`。
- **R-SCALE-02 唯一尺共享**：全图仅一把图形尺 → 视为全局默认，复制给每个 Unit；来源记 `L2_unique_shared`。
- **R-SCALE-03 无前缀多尺**：≥2 把尺且至少一把无前缀 → VL 读前缀兜底（L3）；仍失败 → E004 复核；禁止坐标距离推断。
- **R-SCALE-04 无图形尺**：L1 → `group_no_scale` 复核；L2/L3 → 允许输出并标记 `no_scale`；正文文字尺寸（如"高11厘米"）不作为图形尺的替代。
- **R-SCALE-05 成图与留痕**：每个 Unit 必须带其绑定的尺；共享尺复制；来源与共享标记入台账；纵向尺随组整体旋转，不重排。

### 5.3 命名

- **R-NAME-01**：格式 `原图名称_[seq_id|01]_器物号.png`。
- **R-NAME-02**：器物号冒号统一为连字符（`M4:6` → `M4-6`）。
- **R-NAME-03**：图号从图题提取，剔除图号后的描述性汉字；子编号（`图七a`、`图2-1-16b`）完整保留。
- **R-NAME-04**：同一批次重名 → 追加 `_1`、`_2` 递增；去重注册表按 book 级共享。
- **R-NAME-05**：规则 B 有多个序号时用序号串（如 `图一三_2,3_M4-2.png`）；无序号时用 `01`。
- **R-NAME-06**：防错回退仅限 OCR 漏读且非报警引起的缺失：`原图名_图片内序号.png`；报警场景一律不出图。

### 5.4 数据集形态

- **R-DATA-01**：交付物为 `PNG + pairs.jsonl + ledger.jsonl` 三件套。
- **R-DATA-02**：本地文件系统起步；数据库/对象存储后置，不阻塞 P0。
- **R-DATA-03**：每个 figure 的阶段产物可落盘（文本映射、视图、OCR、映射表、QC 报告），支持断点续跑。
- **R-DATA-04**：输出必须可复现：记录代码版本、配置、模型版本、输入清单。

## 6. 质量与复核

### 6.1 报警码

| 报警 | 触发条件 | 处理 |
|---|---|---|
| E001 | 图注声明序号，图面无对应视图 | 复核，不出图 |
| E002 | 图面有序号视图，图注无对应声明 | 复核，不出图 |
| E003 | 多个带号比例尺无法与视图序号对应 | 复核，不出图 |
| E004 | 比例尺无号且全图多尺 | 复核，不出图 |
| E005 | 多器物但图注无序号列表 | 复核，不出图 |
| E006 | 共享基准线导致掩膜残缺 | 复核，不出图 |
| E007 | 其它硬约束/证据不足（含 VL 决定性门未决） | 复核，不出图 |

### 6.2 自动输出与复核

- **R-QC-01**：仅当映射完整、比例尺已绑（L1）、成图自检通过、无 E001–E007 时自动输出。
- **R-QC-02**：任一硬报警 → `PENDING_REVIEW`，不输出 PNG，携带映射表、缺陷证据、figure_id。
- **R-QC-03**：无描述了文本 → 输出 Pair 但标记 `no_text` 并转复核。
- **R-QC-04**：P0 默认关闭 VLM；可选启用于 L3 比例尺、歧义组仲裁、QC。VLM 只做三态仲裁（True/False/None），不得自动修复、不得替代冻结测试；使用 MaaS `deepseek-v4.1-flash-1017`，失败 fail-closed 转复核。
- **R-QC-05**：VLM 不可用/超时 → fail-closed 转复核，不降级为猜测。
- **R-QC-06**：复核回灌：人工修正 `seq→artifact` 或 `mask→artifact` 后，从映射阶段重入，不重跑分割。

### 6.3 复核队列

- **R-QC-07**：复核任务至少包含：`figure_id`、`artifact_id`（可空）、`seq_ids`、报警码、映射表快照、原图路径、候选图路径。
- **R-QC-08**：复核工具选型后置；队列格式先按 JSONL 定义，保证可迁移到 Label Studio 或自建页面。

## 9. 冻结决定与执行项

### 9.1 已确认

- 8 项边界（输入、Pair、身份、映射、同号/多视图/跨图、成图、复核、输出）。
- R-ID-06 后缀规则：`a/b/c`、`-N` 默认独立器物。
- R-MAP-07a/b/c：N:1 合并 / 1:N 组合图共享或显式拆分 / N:N 位置对应。
- R-SCALE-01–05：前缀组硬绑、唯一尺共享、无前缀多尺复核、无图形尺分流、成图留痕。
- 规则 B 命名使用序号串；无序号用 `01`。

### 9.2 已冻结的 10 项补充决定（2026-11-20）

1. **多面板/拼版图**：V1 不自动裁切；图注器物数与画面独立物件数明显不一致 → `multi_panel` 复核/归档；L3 仅在画面确为单一物件时成立。
2. **跨图线图+版图**：各自成 Pair；另出 `same_artifact_index.jsonl` 关联；流水线内不合并图像。
3. **Pair 元数据与文本长度**：增加 `artifact_name`、`figure_number`、`source_role`；文本全文保留，超过 2000 字标记 `long_text` 复核。
4. **下游数据格式与切分**：流水线只产通用 PairRecord + JSONL；train/val/test 切分与 LLaVA/InternVL 等格式由下游脚本负责。
5. **数据许可、黄金集与复核资源**：仅内部训练使用、不公开发布；黄金集 100–200 图，双人独立标注 + 仲裁；执行人待项目组指定。
6. **VLM 启用**：P0 默认关闭；仅 L3 比例尺、歧义组仲裁、QC 可选启用；使用 MaaS `deepseek-v4.1-flash-1017`，fail-closed 转复核。
7. **运行环境与性能**：CPU 可跑，17 本批处理，单图超时 60s；吞吐/SLA 待基线测量后写入。
8. **复核工具**：先落 JSONL 复核队列；Label Studio/自建后置。
9. **分割方法**：OpenCV 轮廓默认；SAM 是否引入、mask IoU 是否作硬门禁，待基线评估。
10. **数据库/对象存储**：P0 本地文件；PostgreSQL/MinIO 后置。

### 9.3 操作项（不改变需求）

- 黄金集标注/复核执行人与工时：待项目组指定。
- 性能基线（单图耗时、复核率）：首轮跑批后测量并写入 Plan。
- 契约字段（ArtifactMap / PairRecord / 报警码 / 命名）：由契约文件落定后签字。

### 9.4 明确不做/后置

- 跨报告/跨章节同一器物聚合：不做。
- 多器物彩图拆分：不做（L4 归档）。
- 自动猜测缺失映射、bbox 切割、像素补全：不做。

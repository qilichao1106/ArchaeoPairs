# 命名契约

> 需求 V1.0 §5.3；格式固定为 `原图名称_[seq_id|01]_器物号.png`。

## 规则

1. **原图名称**：从 `figure-title` 提取图号（`图2-1-16`、`图七`、`图二六`、`图版204`、`拓片三七`），剔除图号后的描述性汉字。
2. **seq 段**：单序号用该序号；无序号用 `01`；规则 B 多序号用序号串（逗号分隔，如 `2,3`）；N:N 位置对应时用该器物对应的序号。
3. **器物号**：冒号（`:`、`：`、`∶`）统一为连字符 `-`；后缀字母与 `-N` 子编号保留（`M43:75a` → `M43-75a`，`M39:8-1` → `M39-8-1`）。
4. **图号后缀**：`图七a`、`图2-1-16b` 完整保留。
5. **重名**：同一 book 内完全同名 → 追加 `_1`、`_2`（从 `_1` 起），插在扩展名前。
6. **防错回退**：仅 OCR 漏读且非报警引起的缺失 → `原图名_图片内序号.png`；E001–E007 场景不出图。
7. **共享图像**：同一 `seq` 多器物共享图像资产时，`image_path` 可相同；不为了命名差异复制内容相同的 PNG。

## 示例

| 图题 | 器物 | 输出 |
|---|---|---|
| 图2-1-16 M4出土铜舟、盘、圆纹饰拓片 | M4:2（seq 1） | `图2-1-16_1_M4-2.png` |
| 图2-1-5 M4出土铜鼎（M4：6）纹饰 | M4:6（单器物） | `图2-1-5_01_M4-6.png` |
| 图一三 M9出土器物 | M9:6、M9:4（规则 B，seq 1,2） | `图一三_1,2_M9-6.png` |
| 图二四七 M43出土器物 | M43:75a（seq 5） | `图二四七_5_M43-75a.png` |
| 图版204 | M321:2-3（单器物版图） | `图版204_01_M321-2-3.png` |

## 禁止

- 用 bbox/坐标推断命名。
- 丢弃图号字母后缀。
- 把 `M43:75a/b/c` 归一成 `M43-75`。
- 报警场景自动回退命名并出图。
